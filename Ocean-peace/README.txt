# Ocean Peace — Site

## Como abrir
1. Extraia a pasta.
2. Abra o arquivo `index.html` no navegador.

## Como publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Ative o GitHub Pages em Settings > Pages.
4. Use o endereço publicado para gerar o QR code.

## Antes de entregar
- Troque os dados por números confirmados nas fontes.
- Revise o texto da legislação.
- Adicione os nomes da equipe.
- Substitua o espaço `QR` pelo QR code real.
- Teste o site no celular.
